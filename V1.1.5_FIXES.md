# Digital Space Android v1.1.5

## Indoor Home browser

- Adds **Open Indoor Home** while the client is connected to an Area.
- Opens only `https://home.digitalspace.home.arpa/` in an app-owned WebView.
- Answers the WebView client-certificate challenge with the active short-lived
  Area profile certificate and its matching locally stored private key.
- Uses the enrolled device certificate for private API resources requested from
  `api.digitalspace.home.arpa`, matching the server's separate mTLS boundary.
- Rejects redirects, navigation, client-certificate requests, mixed content,
  file access, and content access outside the exact Indoor Home and API hosts.
- Validates the private server certificate against the enrolled Digital Space
  CA and the pinned SHA-256 authority fingerprint. There is no blanket TLS
  error bypass.
- Automatically closes the browser if the device leaves the Area.
- Includes Kotlin compatibility fixes for the WebView progress callback and
  nullable client-certificate key-type list.

The separate device certificate remains dedicated to the Indoor control-plane
API at `api.digitalspace.home.arpa`.
