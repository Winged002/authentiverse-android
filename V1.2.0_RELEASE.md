# Digital Space Android v1.2.0

## NDA lifecycle

- Create and issuer-sign an NDA with a title, purpose, terms, expiry policy,
  one to 100 participants, and one to 1,000 protected file references.
- Export or deliver a recipient-specific encrypted `.dsnda` package containing
  the signed agreement and up to 100 re-encrypted protected files.
- Show received files immediately under **Shared with me**, locked until the
  recipient accepts and countersigns the agreement.
- Sign acceptance and decline decisions independently for each participant and
  verify a returned response before updating its status.
- Revalidate the acceptance signature and expiry policy every time a protected
  file is viewed. Supported image and text formats remain in the in-app managed
  viewer; unsupported formats remain encrypted.

## Product interface

- Reworked the app around five plain-language destinations: Home, Files, NDAs,
  People, and Privacy.
- Added a guided NDA composer, agreement filters, participant status cards,
  clear signing confirmations, and separate manual/Indoor delivery actions.
- Added modern Material cards, simplified connection language, stronger empty
  states, clearer privacy explanations, and a cohesive production palette.

## Compatibility note

Manual `.dsnda` import/export supports the full package size allowed by the
device. Indoor delivery is capped at 64 MiB in the Android client and also
depends on the control panel's configured upload limit. Use manual export for a
larger package or increase the server limit after an infrastructure review.

## Build correction

- Qualified the NDA participant state assignment so it cannot resolve to the
  importer function's `PersistentState` parameter.
- Replaced unavailable Material text-button attributes with portable
  transparent `MaterialButton` styling compatible with Material 1.13.0.
